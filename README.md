# Pustovyi Tutor — Math & Physics Tutoring Site

Static single-page site. No build step, no dependencies.

## Structure
- `index.html` — the whole page
- `assets/` — photo and video files (intro videos in UA/RU, 3 student review videos)

## Deploy
Push to GitHub, then import the repo on vercel.com (Framework Preset: "Other" / static).
